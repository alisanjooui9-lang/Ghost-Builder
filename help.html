👋 چطور با Ghost Builder کار کنیم؟

Ghost Builder یک محیط ساخت پروژه برای ایجاد سایت، اپلیکیشن و بازی است. بدون نیاز به شروع از صفر، می‌توانید از قالب‌ها استفاده کنید، پروژه را شخصی‌سازی کنید و نتیجه را در پیش‌نمایش مشاهده کنید.

🔎

🚀 شروع کار

برای ساخت اولین پروژه کافی است نوع پروژه خود را انتخاب کنید.

🌐
Website ساخت صفحات وب و سایت‌های شخصی یا تجاری.
📱
App ساخت رابط پروژه‌های موبایلی.
🎮
Game 2D ساخت بازی‌های دوبعدی.
🧊
Game 3D ساخت پروژه‌های بازی سه‌بعدی.
🧩
Templates شروع سریع با قالب‌های آماده.
💾
Local Storage ذخیره پروژه‌ها روی دستگاه شما.

1

تغییرات را ذخیره کنید و نتیجه را در پیش‌نمایش ببینید.

🚀 انتشار پروژه

بخش Publish برای آماده‌سازی نسخه قابل مشاهده پروژه استفاده می‌شود.

نسخه Web

  1. پروژه را ذخیره کنید.
  2. وارد Publish شوید.
  3. خروجی Web را انتخاب کنید.
  4. لینک Preview پروژه را ایجاد کنید.
  5. لینک را باز یا کپی کنید.

نسخه APK

برای تبدیل نسخه Web به APK، در معماری فعلی می‌توان از یک سرویس Web-to-APK خارجی استفاده کرد. ابتدا نسخه Web پروژه را آماده کنید و سپس URL آن را به سرویس تبدیل APK بدهید.

💡 در نسخه‌های آینده می‌توان یک Build Service اختصاصی به Ghost Builder متصل کرد تا فرآیند ساخت APK مستقیماً داخل پلتفرم انجام شود.

❓ سوالات متداول

بله. نسخه فعلی اطلاعات پروژه‌ها را در Local Storage مرورگر ذخیره می‌کند.

بله. از Projects پروژه موردنظر را انتخاب کرده و وارد Builder شوید.

خیر. ساختار Ghost Builder برای Website، App و Game 2D/3D طراحی شده است.

در نسخه فعلی خروجی Web و Preview آماده می‌شود. برای APK هنوز به سرویس Build خارجی یا Backend اختصاصی نیاز است.

بله. قالب صرفاً نقطه شروع پروژه است و می‌توانید عناصر و تنظیمات آن را در Builder تغییر دهید.

بله. از صفحه Projects گزینه حذف پروژه را انتخاب کنید.
