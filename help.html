شروع کار

برای شروع، از صفحه اصلی روی «پروژه جدید» بزنید، نوع پروژه را انتخاب کنید و وارد Builder شوید.

🌐

ساخت وب‌سایت

در Builder می‌توانید عنوان، متن، دکمه، کارت، تصویر، فرم و بخش‌های مختلف سایت را ایجاد کنید.

📱

ساخت اپلیکیشن

پروژه App را انتخاب کنید و رابط کاربری و بخش‌های موردنیاز اپلیکیشن را در Builder طراحی کنید.

🎮

ساخت بازی

Ghost Builder برای پروژه‌های بازی 2D و 3D طراحی شده و در نسخه‌های آینده امکانات بیشتری دریافت می‌کند.

🎨

کیفیت و رزولوشن

کیفیت پروژه و رزولوشن را می‌توانید از تنظیمات پروژه مشخص کنید؛ از کیفیت پایین تا Ultra و رزولوشن‌های بالاتر.

🌍

انتشار نسخه وب

پس از تکمیل پروژه، وارد صفحه انتشار شوید و لینک نسخه وب پروژه را دریافت کنید.

📦

دریافت APK

نسخه فعلی Ghost Builder لینک وب پروژه را آماده می‌کند. برای APK می‌توان از سرویس Web به APK استفاده کرد.

📁

مدیریت فایل‌ها

از بخش Media می‌توانید تصاویر، ویدیوها و فایل‌های پروژه را مدیریت کنید.

❓ سوالات متداول

Ghost Builder یک محیط برای ساخت وب‌سایت، اپلیکیشن و بازی است که هدف آن ساده‌کردن روند ساخت پروژه برای کاربران است.
هدف Ghost Builder این است که بخش زیادی از ساخت پروژه بدون نیاز به کدنویسی انجام شود. امکانات پیشرفته‌تر می‌توانند در نسخه‌های بعدی اضافه شوند.
در نسخه فعلی، اطلاعات پروژه‌ها در حافظه محلی مرورگر دستگاه ذخیره می‌شود.
صفحه Publish لینک نسخه وب پروژه را آماده می‌کند. برای تبدیل مستقیم Web به APK، یک سرویس Build خارجی یا زیرساخت اختصاصی لازم است.
نوع پروژه Game 3D در Ghost Builder وجود دارد. سیستم کامل بازی‌سازی سه‌بعدی می‌تواند در مراحل بعدی توسعه داده شود.
