📱 ساخت APK

⚠️ Ghost Builder در حالت فعلی یک سیستم ساخت APK روی خود GitHub Pages ندارد. ابتدا باید نسخه Web پروژه آماده شود و سپس لینک آن را در یک سرویس معتبر Web → APK وارد کنید.
1
پروژه را آماده کنید ابتدا نسخه وب پروژه را ذخیره و آماده کنید.
2
لینک پروژه را دریافت کنید لینک نسخه وب را از قسمت بالا کپی کنید.
3
سرویس Web → APK یک سرویس معتبر تبدیل Web به APK را باز کنید و لینک پروژه را وارد کنید.
4
نام و آیکون برنامه نام برنامه، آیکون و تنظیمات موردنیاز را در سرویس انتخاب کنید.
5
دریافت APK بعد از ساخت، فایل APK را از همان سرویس دریافت کنید.
