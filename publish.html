📱

خروجی APK

Ghost Builder در نسخه فعلی، پروژه وب شما را آماده می‌کند. برای تبدیل آن به APK می‌توانید لینک وب پروژه را داخل یک سرویس Web → APK قرار دهید.

1
ابتدا پروژه وب خود را منتشر کنید.
2
لینک پروژه را از کادر بالا کپی کنید.
3
لینک را در یک سرویس معتبر تبدیل Web → APK وارد کنید.
4
نام برنامه، آیکون و تنظیمات APK را انتخاب کنید.
5
فایل APK ساخته‌شده را دریافت کنید.
⚠️ برای ساخت APK واقعی، یک سرویس Build لازم است. در نسخه فعلی Ghost Builder، خود GitHub Pages امکان ساخت مستقیم APK را ندارد.
